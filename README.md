# WPF 飲料訂購系統

這是一個使用 C# 與 WPF 開發的桌面應用程式，提供使用者直覺的介面來進行飲料點餐、記錄內用外帶狀態，並自動計算總金額與折扣。

## 功能特色
- **防呆輸入機制：** 利用 Slider 滑桿綁定數值，阻絕非數字字元輸入錯誤。
- **自動化計價與折扣：** 內建階梯式折扣邏輯（滿 200 打 9 折、滿 300 打 85 折、滿 500 打 8 折）。
- **動態明細生成：** 利用 Dictionary 資料結構彙整使用者的點擊狀態，即時運算並印出完整的結帳明細。

## 開發技術
- **語言：** C#
- **介面框架：** .NET WPF (XAML)
- **開發環境：** Visual Studio 2022

## 如何執行
1. 將此專案 Clone 到本機：`git clone [請替換成你的GitHub專案網址]`
2. 使用 Visual Studio 開啟 `WpfApp3.sln` 方案檔。
3. 按下 `F5` 或點擊上方的綠色「開始」按鈕建置並執行程式。
